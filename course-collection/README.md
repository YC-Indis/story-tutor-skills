# Story Hero Academy complete collection

`Story-Hero-Academy-Complete-Self-Contained.html` is the mobile-friendly,
self-contained course collection for Chapters 1–9.

- All 4,302 image references are embedded directly as Base64 data URLs.
- The file does not depend on local `assets` folders or external image hosts.
- The navigation includes desktop sidebar collapse, mobile navigation, search,
  chapter links, lesson links, previous/next links, and reading progress.
- The file is approximately 539 MB and is stored with Git LFS.

Download the HTML file before opening it. For mobile use, open the downloaded
file with Chrome, Edge, or another full browser instead of an in-app previewer.
If a phone cannot comfortably parse a single file of this size, use a
chapter-split build instead.
